# 出处与写法

追问图和灵感笔记共用的规则：出处怎么标、外部论文怎么核实、页面支持哪些写法。

## 来源标签

让读者分得清哪些是论文说的、哪些出自别处、哪些是推出来的。只有五种，指不到论文或教材的一律标【推断】：

- `【原文 · §2b p.994「the slope parameter is diagnosed」；Tab. 1】`：本文（追问图读的那篇）内容，出处精确到节、图表、页。每个页码后用「」照抄该处原文中连续 4–8 个英文词，用户点页码时 PDF 会定位到这一行；选同一行内、不跨行断词、不含公式和特殊符号的句子；
- `【论文 · Fletcher 1962 p.12「…」】`：其他论文的内容，多篇用“；”隔开，同一篇的多处页码也用“；”隔开，如 `【论文 · Khain 2015 p.249「…」；p.253「…」；Liu 2023 p.762「…」】`，只有页码的一段归前面最近的论文；名字和页码之间可写节号、式号，如 `【论文 · K15 §2 式 (1) p.253「…」】`。读过该文 PDF 的写页码和「」引文，页码是该文的期刊页码；只核实了存在的只写名字，页面显示为浅色，内容视同未核实；
- `【教材 · Pruppacher & Klett 1997, Ch. 9】`：教科书层面的基础知识；
- `【推导 · 由 (1) 式对 m 积分】`：由前文和已标出处的内容推出，读者能逐步核对，写明依据；
- `【推断】`：AI 推出且未核实的内容，页面上显示为橙色提醒；对照过本机代码、配置的写成 `【推断 · 已对照本机 文件路径】`。

“·”也可写成“：”。标签单独一行时放在所标段落之前；灵感笔记里也可以写在句末，只标这一句。

## 外部论文

- 【论文】里的名字都登记在元信息 `refs`，如 `refs: Fletcher 1962=10.1007/978-94-010-3378-8, KC00=10.1029/2000JD900002`，页面据此把名字做成链接；没有 DOI 的可填网址。
- 本机有该文 PDF 时（如在文献库里），DOI 后用“|”接 PDF 相对本文件的路径和该 PDF 第 1 页的期刊页码，如 `Khain 2015=10.1002/2014RG000468 | ../../pdf/Khain2015.pdf | 247`；页码要打开 PDF 第 1 页核对。预览中点名字打开这个 PDF，点标签里该文的页码跳到对应页并定位「」引文；文件不在时改在浏览器打开 DOI。
- 登记前用 Crossref（`https://api.crossref.org/works?query.bibliographic=…`）或 Semantic Scholar 查到该文，题名、第一作者、年份都对上，DOI 能打开。查不到的不登记，内容改标【推断】并注明“出处待确认”。
- 追问图先用本文参考文献表里的论文；本文没引用、由 AI 引入的，同样核实后登记，并在卡片里注明“本文未引用”。
- 查到只说明该文存在，不说明它支持这句话：只核实了存在的，不写成“该文指出……”的具体结论和数值；要写，先读该文 PDF，带页码和引文。

## 教材

概念在本领域标准教材里有成章讲解（如 Köhler 理论、经典核化理论、原始方程组），标【教材】，不必找论文、不加链接。书名优先从 `个人偏好.md` 的书单里选，书单外的写全作者、年份、书名；章节号对照过目录或 PDF 才写，不凭记忆写。

## 页面支持的写法

| 写法 | 效果 |
|---|---|
| `## 标题 {#id parent=父id rel=next status=pending}` | 追问图的节点，整行写完；不写 parent 即为主干；标题以 `§` 或“附录”开头的子节（如挂在 §2 下的 §2a）与主干一样带左侧竖条；与父节点的连线默认是指向父节点的实线箭头，`rel=next` 指向子节点，`rel=assoc` 画成虚线；`status=pending` 暂挂（虚线框），`status=extra` 超出本文（米黄框）。id 只用英文字母、数字、`_`、`-`，写中文这一行就不算节点 |
| `## 标题`、`###`、`####` | 灵感笔记的各级标题；卡片里只用 `###`、`####` |
| `[文字](#id)` | 卡片链接 |
| `$N_{0r}$`；`$$…$$`（可跨多行） | 行内公式；行间公式（浅蓝框，KaTeX 排版） |
| `**粗**` `*斜*` `` `码` `` `> 引用` `---` 表格 列表 | 常规 Markdown |
| `p.994「…」`、`p.998–999`、`Fig. 8`、`Figs. 8 and 9`、`Tab. 1` | 卡片里任何位置都可点（需 PDF Viewer 扩展）：页码跳到该页并定位「」里的原文，引文本身不显示；图表跳到 `figures` 登记的页，子图 `Fig. 8a` 按 Fig. 8 |
| 元信息 `pdf`、`firstPage`、`figures` | 追问图读的论文 PDF 相对本文件的路径；PDF 第 1 页的期刊页码；各图表的期刊页码，如 `Fig. 1=993, Tab. 1=994, Fig. A1=1006` |
| 元信息 `refs`；`【论文 · 名字 p.12「…」】` | 外部论文的 DOI（或网址）登记，可再用“|”接本机 PDF 路径和第 1 页期刊页码；标签里登记过的名字可点：有本机 PDF 时在预览中打开它，否则在浏览器打开该文；该文登记了 PDF 和页码时，标签里的页码跳到那篇对应页并定位引文，否则只显示 |
| `[文字](https://…)`、`[文字](路径)` | 网址在浏览器打开；路径相对本文件，也可写绝对路径，含空格或括号时写成 `[文字](<路径>)`。追问图 `_twig.md#id` 在预览中打开那张卡片，灵感笔记 `_idea.md#3.2` 在预览中滚到以它开头的标题；其他文本文件在编辑器打开，`#L42` 跳到第 42 行，Markdown 的 `#3.2` 跳到以它开头的标题；PDF 的 `#page=5` 跳到 PDF 第 5 页；其他文件、文件夹用系统默认程序打开 |
| 元信息 `zotero` / `citekey` | 扩展填的文献编号（Zotero 的条目编号 / `.bib` 文件的 citation key），按文献库分类整理文件夹、本机找不到 `pdf` 指向的文件时按它查 PDF；不要改 |

追问图的行内公式换成 Unicode 字符显示，只支持上下标、希腊字母、常用运算符、`\mathrm{}`，用来写简单的量和关系式；分数、积分上下限、根号、多行推导写成行间公式，按标准 LaTeX 写，由 KaTeX 排版（多行用 `aligned` 环境）。灵感笔记的行内公式也由 KaTeX 排版，可按标准 LaTeX 写。
