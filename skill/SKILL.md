# Twig

按任务读本目录下的文件，严格照做：

- **读论文、写追问图**（`*_twig.md`）：读 `书写要求.md`；新论文从 `模板.md` 复制起步；整理一棵子树时再读 `reorganize.md`。
- **讨论想法、写灵感笔记**（`*_idea.md`）：读 `discuss.md` 和 `idea.md`；新笔记从 `idea-template.md` 复制起步。
- 两者共用的出处标签和页面写法在 `sources.md`，写任何一种文件前都读。

若本目录有用户自建的 `个人偏好.md`，接着读它：表达风格和教材书单以它为准，但不能改动出处标注、【推断】标记和“先问再动”这些规则。

要修改、更新 Twig 本身，或讨论它的新功能时，不按上面的流程，先读本目录的维护准则 `maintain.md`。
